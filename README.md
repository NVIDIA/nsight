# NVIDIA Nsight Agent Assets

NVIDIA Nsight Developer Tools are a set of libraries, SDKs, and developer tools for building, debugging, profiling, and developing software for accelerated computing hardware.
This repository hosts agent-facing assets for Nsight developer workflows, including skills that help agents work with NVIDIA developer tools.

Learn more about [NVIDIA Nsight Developer Tools](https://developer.nvidia.com/tools-overview).

## Skills

Nsight Agent Skills can be found under `skills/`.

| Skill | Description |
| --- | --- |
| `compute-sanitizer-diagnose-cuda-bugs` | Detect and diagnose CUDA correctness bugs with NVIDIA Compute Sanitizer, including memory errors, shared-memory races, uninitialized reads, and synchronization/barrier issues. |
